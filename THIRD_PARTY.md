# Third-party licenses

Direct runtime dependencies only (not transitive, not build/dev tooling
except where noted). Generated by reading installed package metadata
directly — `node -e "require('<pkg>/package.json').license"` for the
frontend and Python's `importlib.metadata.metadata(<pkg>)['License-Expression']`
for the backend — rather than installing a license-scanning tool, per the
"no large installs" constraint. Regenerate by re-running those one-liners
against `frontend/package.json`'s `dependencies` and `requirements.txt`
if either changes.

All licenses below are OSI-approved open source licenses, **except** the
three `@fontsource/*` font packages — see the flag below.

**Flag:** OFL-1.1 (SIL Open Font License 1.1) is a legitimate, widely-used
free/open license — it's FSF- and Debian-free-software-approved, and is
what Google Fonts ships IBM Plex and Manrope under — but to the best of
available knowledge it does **not** appear on OSI's approved-license list,
which is scoped to software rather than fonts. This was not independently
re-verified against a live copy of OSI's list in this session; treat it as
a documented flag to confirm, not a settled legal conclusion. It imposes no
restriction relevant to this project (bundling and redistributing the font
files is explicitly permitted).
